# Roadmap

Seeded public issues for v0.2 and later:

1. [Canton Network adapter](https://github.com/vishnugovind10/control-probe/issues/1): read-only ledger state via Canton JSON API.
2. [Corda adapter](https://github.com/vishnugovind10/control-probe/issues/2): vault state queries via Corda RPC.
3. [Continuous monitoring mode](https://github.com/vishnugovind10/control-probe/issues/3): run on a schedule and emit alerts on assertion failure.
4. [Historical calibration](https://github.com/vishnugovind10/control-probe/issues/4): calibrate shock parameters from on-chain history.
5. [Control library](https://github.com/vishnugovind10/control-probe/issues/5): curated MiCA Title III and Title IV control specifications.
6. [Report diff](https://github.com/vishnugovind10/control-probe/issues/6): compare two probe results and surface material changes.
7. [CI/CD integration guide](https://github.com/vishnugovind10/control-probe/issues/7): GitHub Actions and GitLab CI examples.
