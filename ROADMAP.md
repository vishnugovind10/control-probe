# Roadmap

Seeded public issues for v0.2 and later:

1. Canton Network adapter: read-only ledger state via Canton JSON API.
2. Corda adapter: vault state queries via Corda RPC.
3. Continuous monitoring mode: run on a schedule and emit alerts on assertion failure.
4. Historical calibration: calibrate shock parameters from on-chain history.
5. Control library: curated MiCA Title III and Title IV control specifications.
6. Report diff: compare two probe results and surface material changes.
7. CI/CD integration guide: GitHub Actions and GitLab CI examples.
