# Security Policy

## Reporting a vulnerability

Please report security issues privately through the repository security advisory flow once the public repository is created. Do not open public issues for exploitable vulnerabilities.

## Scope

Security reports are most useful when they involve:

- Unsafe expression evaluation.
- Adapter behavior that could leak secrets.
- Incorrect handling of RPC or fixture data that changes assertion outcomes.
- CLI behavior that writes outside the requested output location.

This project does not require private keys and should not receive them.
